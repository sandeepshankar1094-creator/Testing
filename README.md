# Angular + Node.js Starter

A minimal Angular frontend and Express API in one npm-workspaces project.

## Requirements

- Node.js 22.22.3 or newer
- npm

## Run locally

```sh
npm install
npm run dev
```

Open the Angular app at <http://localhost:4200>. Its `/api` requests are proxied
to the Express API at <http://localhost:3000>.

## Build the frontend

```sh
npm run build
```
